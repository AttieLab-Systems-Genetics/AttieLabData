# Research Drive Data for Attie Lab

Attie Lab data reside in two
[ResearchDrive (`RD`)](https://researchdrive.wisc.edu/)
folders.
Depending on one's operating system, the root path
`$RD/` is mounted as `W:` (Windows)
or `/Volumes/` (MacOS).

## `adattie` on `$RD/`

This was the orginal data folder for the Attie Lab,
and it is now almost completely full.
Much of the data consist of microarray expression arrays raw data.
In addition, it contains historical records for
lab members.
Primary concern is `$RD/adattie/General`,
and in there data related to the various Founder projects.

- `adattie/General/founder_diet_study`: raw and harmonized data for Founder apps, notably
<https://connect.doit.wisc.edu/FounderDietStudy>
- `adattie/General/founder_calcium_website`: raw and harmonized data for Founder apps, notably
<https://connect.doit.wisc.edu/FounderCalciumStudy>

See also [foundrShiny](https://byandell-sysgen.github.io/foundrShiny/)
and the related repositories that were used to
build these data and tools.

## `mkeller3` on `$RD/`

This was added later and has the organized DO1200
project and most current projects.
Primary concern is `$RD/mkeller3/General`.

- `mkeller3/General/main_directory`: DO1200 project
  - See [sysgenDO1200](https://github.com/AttieLab-Systems-Genetics/sysgenDO1200)
- `mkeller3/General/Projects2`: Mark Keller workflows
  - See [`mkeller3Projects2](https://github.com/AttieLab-Systems-Genetics/mkeller3Projects2)
